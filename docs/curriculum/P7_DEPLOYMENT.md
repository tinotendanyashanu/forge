The off-VM blob returned HTTP 200 with the correct length, and its encrypted bytes matched the local file's SHA-256: `c840b9eb9b716b3c525e1e4a74a3410195f2856874cf77e6c857c9b6411ca1f5`. The verification did not decrypt or export learner rows.

The guarded release followed the private Azure Run Command procedure: verify baseline/configuration and release objects, back up, briefly stop web/API writes, capture a consistent read-only snapshot, check out the exact release, run the existing full seed once, compare preservation fingerprints, then start and verify the services. PostgreSQL stayed running. No migration or frontend-source change was needed; the existing Next.js build was retained.
